ai4research flow (for solving an existing problem):
- input: topic
- agent: scan the latest progress of technology under that topic, generate analysis on that topic (find out what's the issue, and how can we improve on it)
- agent generate 5 or 6 requirements (in sys v2 which addresses the issue) for the research, but human do final decision, confirm the requirements.
- after decision made, ai generate research design
- agents use ai coding capabilities to generate POC demo.
- agents do benchmark testing on the benchmark demos
- use to define the logic and world model to the agent, model can also be part of the verification (cuz output not stable)
- have a agent to review the benchmark results (if demo work or not)
- in the end model will be released to opensource community
- V-model (waterfall model) will be used in the pipeline
	- Requirement -> User Acceptance test with test case ready (manifestation of the required specs)
	- Design -> Integration test
	- Coding -> Unit test
