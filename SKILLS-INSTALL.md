# Optional third-party skills → see INSTALL.md

Third-party skill installation is covered in the canonical install guide. See
**[INSTALL.md](INSTALL.md)** — section *Optional third-party skills*.

In short: Solar's `skills-*` components install bundled skills under
`~/.claude/skills/`; any third-party skill pack is an optional enhancement,
installed separately under `~/.claude/skills/`, only after you approve it, and
never overwriting your existing skills.
