Build a small command-line utility named `slugcase` that reads lines from
standard input and prints URL-safe slugs. It must lowercase text, collapse
whitespace and punctuation into single hyphens, trim leading or trailing
hyphens, and preserve digits. Include focused tests for empty input, repeated
punctuation, mixed case, and multiple input lines. Keep the implementation
dependency-free and provide a short usage note.
