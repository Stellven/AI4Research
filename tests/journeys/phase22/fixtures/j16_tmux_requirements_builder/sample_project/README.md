# Checkout Discount Fixture

This tiny project is the sandbox target for Phase 22 J16. The intended behavior is:

- trial accounts receive 0 percent discount;
- non-trial pro accounts receive 20 percent discount;
- non-trial enterprise accounts receive 30 percent discount;
- ordinary non-trial accounts receive 5 percent discount.

The fixture starts with a real bug so the journey can prove defect repair with a failing baseline test and a passing post-repair test.
