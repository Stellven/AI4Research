# Tree of Thoughts: Deliberate Problem Solving with Large Language Models

- **id:** tot2023
- **authors:** Yao, Yu, Zhao, Shafran, Griffiths, Cao, Narasimhan
- **year:** 2023
- **venue:** NeurIPS
- **topics:** test-time-recursive-thinking

## Summary
Generalizes chain-of-thought into a search over a tree of intermediate "thoughts,"
letting the model explore, self-evaluate partial solutions, and backtrack at test time.

## Key claims
- Framing reasoning as search over a tree of intermediate thoughts, with lookahead and
  backtracking, substantially improves performance on tasks requiring planning.
- The model itself provides state-evaluation heuristics to prune branches, a form of
  test-time self-assessment.
- Deliberate test-time search can raise success rates on hard puzzles by large margins
  versus single-path chain-of-thought.

## Limitations
- Search multiplies inference cost relative to a single forward pass.
- Effectiveness depends on the reliability of the model's own state evaluations, which
  can be miscalibrated.
