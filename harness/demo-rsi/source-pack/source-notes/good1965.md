# Speculations Concerning the First Ultraintelligent Machine

- **id:** good1965
- **authors:** I. J. Good
- **year:** 1965
- **venue:** Advances in Computers, vol. 6
- **topics:** recursive-self-improvement, rsi-safety-governance

## Summary
Foundational essay introducing the "intelligence explosion" idea: a machine that
can design machines better than itself could trigger a rapid recursive cascade of
self-improvement, leaving human intelligence far behind.

## Key claims
- An ultraintelligent machine is defined as one that can far surpass all the
  intellectual activities of any human, including the activity of machine design.
- Because designing better machines is itself an intellectual activity, such a
  machine could design an even better machine, yielding a recursive "intelligence
  explosion."
- The first ultraintelligent machine is characterized as the last invention
  humanity need ever make, provided it stays controllable.

## Limitations
- Speculative and non-empirical; predates modern ML.
- Assumes machine-design ability transfers cleanly across capability levels; gives
  no mechanism or rate for the proposed cascade.
